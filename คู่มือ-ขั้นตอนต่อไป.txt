PART 1: เตรียมเครื่อง — Login clasp (ทำครั้งเดียวตลอดชีพ)
=====================================================================

1. กดปุ่ม Windows บนคีย์บอร์ด (หรือกด Win+R)
2. พิมพ์ cmd → กด Enter
3. หน้าต่างสีดำจะเปิดขึ้นมา
4. พิมพ์คำสั่งนี้ลงไป แล้วกด Enter:

    clasp login

5. หน้าต่างเบราว์เซอร์จะเด้งขึ้นมา
6. มันจะถามว่า "Choose an account" → คลิกเลือก Gmail ของคุณ
7. หน้าถัดไปจะขึ้นว่า "Google hasn't verified this app"
   → คลิก "Advanced" (ด้านล่างซ้าย)
   → คลิก "Go to Google Apps Script API (unsafe)"
8. หน้าถัดไปจะถามสิทธิ์ → คลิก "Allow"
9. หน้าจอจะขึ้นว่า "Successfully logged in" หรือ "Authorization successful"
10. ปิดเบราว์เซอร์ → กลับมาที่หน้าต่าง Terminal สีดำ
11. Terminal จะขึ้นว่า "Authorization successful" หรือ "Logged in as ..."
12. ✅ เสร็จ PART 1 — เปิด Terminal ค้างไว้

PART 4: Copy Script ID
=====================================================================

4.1 ใน Apps Script Editor
4.2 ดูที่แถบด้านซ้าย — จะมีปุ่มรูปเฟือง ⚙️ (Project Settings)
4.3 คลิก ⚙️
4.4 จะมีช่องทำเครื่องหมาย: "Show "appsscript.json" manifest file..."
4.5 คลิก ✔️ ติ๊กถูก
4.6 หน้าจะ refresh
4.7 ดูตรงกลางหน้า — หัวข้อ "IDs"
4.8 จะเห็น "Script ID" — เป็นตัวอักษรยาวๆ เช่น:
    AKfycbwxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
4.9 ใช้เมาส์ลากคลุม Script ID ทั้งหมด → Ctrl+C (Copy)
4.10 ✅ เสร็จ PART 4 — มี Script ID ใน clipboard

PART 5: ตั้งค่า Script ID ใน VS Code
=====================================================================

5.1 เปิด VS Code (น่าจะเปิดอยู่แล้ว)
5.2 ด้านซ้าย VS Code → หาไฟล์ apps-script → .clasp.json
5.3 คลิกเปิดไฟล์ .clasp.json
5.4 เนื้อหาข้างในจะเป็นแบบนี้:

5.5 ลบ YOUR_SCRIPT_ID_HERE
5.6 วาง Script ID ที่ copy มา (Ctrl+V)
5.7 หน้าตาเป็นแบบนี้:

    {"scriptId":"AKfycbwxxxxxxxxxxxxxxxxxxxxxxxx","rootDir":"."}

5.8 Ctrl+S เซฟ

PART 8: Deploy เป็น Web App
=====================================================================

8.1 ใน Apps Script Editor
8.2 มุมขวาบน → กดปุ่ม "Deploy" สีฟ้า
8.3 เลือก "New deployment"
8.4 คลิกไอคอน ⚙️ (Select type)
8.5 เลือก "Web app"
8.6 กรอกข้อมูล:
    - Description: ESAS v1 (พิมพ์อะไรก็ได้)
    - Execute as: Me (your-email@gmail.com)
    - Who has access: Anyone
8.7 กด "Deploy"
8.8 จะมีหน้าต่าง Authorize access เด้งขึ้นมา → กด "Authorize access"
8.9 เลือกบัญชี → กด Allow
8.10 ❗ หน้าต่างจะแสดง URL

     https://script.google.com/macros/s/AKfycbxxxxxx/exec

8.11 คลิก "Copy" หรือใช้เมาส์ลากคลุม → Ctrl+C
8.12 ❗ เก็บ URL นี้ไว้ดีๆ!!
8.13 กด "Done"
8.14 ✅ เสร็จ PART 8 — ได้ URL Web App แล้ว

PART 13: FAQ (คำถามที่พบบ่อย)
=====================================================================

Q: URL Apps Script เปลี่ยนทุกครั้งที่แก้ไขไหม?
A: ถ้า clasp deploy แบบ new deployment → URL ใหม่
   แต่ถ้า Deploy ผ่าน Apps Script Editor → เลือก "Manage deployments"
   → Edit → Version: New → Deploy → URL เดิม!

Q: ต้องเปิด Terminal ค้างไว้ตลอดไหม?
A: Terminal ที่รัน npm run dev ต้องเปิดค้างไว้
   Terminal clasp push ใช้เฉพาะตอนอัพเดท Apps Script

Q: ข้อมูลหายไหม?
A: ไม่หาย — ข้อมูลทั้งหมดอยู่ใน Google Sheets
   มี Auto-save + Version history

Q: อยากให้เพื่อนร่วมงานใช้ด้วย?
A: ส่ง URL Apps Script + token ให้ → เปิดฟอร์มในมือถือได้เลย
   หรือแชร์ Google Sheet ให้ → ดูข้อมูลได้

Q: ถ้าอยากใช้ระบบโดยไม่เปิด Terminal?
A: Deploy Netlify (PART 14 — ทำทีหลัง)
   แล้วเปิดเว็บจาก URL Netlify ได้เลย ไม่ต้องเปิด Terminal

⚡ ขั้นตอนโดยย่อ — กรณีปิดคอม แล้ววันถัดไปมาเปิดใหม่

สิ่งที่เปลี่ยนไปหลังปิดคอม:
  ❌ Terminal ที่รัน npm run dev — ปิดไปแล้ว (ต้องเปิดใหม่)
  ❌ localhost:5173 — เข้าไม่ได้ (ต้องรันใหม่)
  ✅ Google Sheet + Apps Script — ยังอยู่ (อยู่ใน Cloud ไม่หาย)
  ✅ ข้อมูลทุกอย่าง — ยังอยู่ (Google Sheets auto-save)
  ✅ ไฟล์โค้ดใน VS Code — ยังอยู่ (แก้ไว้ครบ)

สิ่งที่ต้องทำ:

1. เปิด Terminal (Win+R → cmd → Enter)
2. cd C:\Users\mark4\VS Code\palliative-care-app\frontend
3. npm run dev
4. เปิด Chrome → http://localhost:5173/login
5. Login: admin / admin123
6. ✅ ใช้ต่อได้เลย

* Apps Script ไม่ต้องเปิดใหม่ — มันทำงานบน Google Cloud ตลอดเวลา
* ถ้าจะแก้ Apps Script → clasp push (ไม่ต้อง login ใหม่ clasp จำไว้แล้ว)
